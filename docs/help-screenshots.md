# ヘルプのスクリーンショット

ヘルプ（`/#/help`、src/pages/HelpPage.tsx）はスクリーンショットのスライドショーです。
スクリーンショットと強調の丸の位置は、スクリプトで自動生成します。
画面を変えたら撮り直してください。

## 撮り直す

```bash
pnpm shots
```

- 日本語と英語の画面を、スマホ幅（390×680、2倍密度）で撮ります。
- 出力: `src/assets/help/<ja|en>/<id>.webp` と `src/assets/help/shots.json`（画像の大きさと丸の位置を % で）。
- 1枚だけ直すとき: `pnpm shots --lang=ja --only=observe`（`--only` はカンマ区切りで複数可）。他の画像と `shots.json` の他の項目はそのまま残ります。
- 20秒ほどで終わります。
  インストール済みの Google Chrome を使います。
  Chrome がなければ `pnpm exec playwright install chromium` を一度実行してください。

## AI は呼ばない

- 探究のデータは src/dev/demo.ts に書いてあります（「聞く: listen / hear」の例文・観察・仮説・翻訳テスト・まとめ・ノート1件）。
- スクリプトは自分で Vite の開発サーバーを別ポートで立て、`/#/dev/seed?lang=ja&auto=1` でこのデータを IndexedDB に入れてから撮ります。
- AI のボタンは押しません。
  開発サーバーの外への通信はすべて遮断するので、無料枠が減ることはありません。
- `/#/dev/seed` は開発サーバーでだけ開けます（本番ビルドには入りません）。
  手元のブラウザで開くと、そのブラウザの探究とノートがデモのデータで置き換わるので注意してください。

## しくみ

scripts/help-shots.ts の `shots` に、スライドごとの手順を書いています。

| 項目 | 内容 |
|---|---|
| `id` | 画像のファイル名。HelpPage.tsx の `slides` の `id` と対応 |
| `prepare` | その画面にする操作（ページを開く、ダイアログを開く、文字を選ぶ…） |
| `rings` | 丸で囲む要素。1つの丸 = 要素のリスト（まとめて囲む） |
| `scroll` | 丸がほぼ真ん中に来るようにスクロールする（ダイアログでは不要） |

- 丸は画像に焼き込まず、ヘルプページが `shots.json` の位置に重ねて描きます。
  撮り直すと丸も一緒に動きます。
- 撮るときはアプリのヘッダーを隠します（ヘルプページのヘッダーと二重になるため）。
- 探究のカードは `#card-demo-<種類>`（ids は demo.ts の `demoCardIds`）で探します。
  カードの中のボタンは表示名（日英どちらにも合う正規表現）で探します。

## 画面が変わってスクリプトが止まったとき

- エラーに出た `id` のスライドの `prepare` か `rings` を、新しい画面に合わせて直します。
- 探究ページの作りが変わってカードが増えたり減ったりしたときは、src/dev/demo.ts のデータも合わせます。
- 直したら `pnpm shots --only=<id>` で撮って、`pnpm dev` の `/#/help?s=<番号>` で丸の位置を確かめます。

## スライドを足す

1. HelpPage.tsx の `slides` に `{ id, title, body }` を足す（見出しは絵文字付きの1行、本文は1〜2文）。
2. help-shots.ts の `shots` に同じ `id` の手順を足す。
3. `pnpm shots` を実行する。

画像がまだないスライドは、点線の枠に見出しだけが出ます。
英語の画像がないときは日本語の画像を使います。
